Справка

Modrinth: поиск делается через публичное API. Для скачивания доступна прямая ссылка на файл, если выбран файл.

CurseForge: для API нужен токен. В браузере запросы могут не проходить из‑за CORS. Если так — разверните маленький прокси (например, Cloudflare Worker / Vercel / Nginx) и проксируйте запросы к api.curseforge.com.

Примечание: вставленный токен хранится в localStorage. Это не безопасно для общих компьютеров.
Сделано как одностраничный клиент. Если CurseForge API не доступен из браузера — используйте прокси.
